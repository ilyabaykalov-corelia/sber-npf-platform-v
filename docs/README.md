# Документация Platform V

Состояние локальных исходников на 16 сентября 2026 года.

1. [Продукт](product.md) — роль комплекта и поддерживаемые сценарии.
2. [Реализация](implementation.md) — модель, процессы, права и контракты.
3. [Операции](operations.md) — упаковка, проверки, установка и ограничения.
4. [Инструкции агента](../AGENTS.md).

В общей рабочей папке доступны [документация Corelia](../../corelia/docs/README.md), [клиент](../../sber-npf-react/docs/README.md), [локальная база знаний СберТех](../../документация/knowledge-base/README.md). Они находятся за пределами этого Git-репозитория.

Документация описывает имеющийся комплект, включая сохранённые legacy-настройки. Она не подтверждает, что этот комплект опубликован на стенде. Результаты старых экспериментов не служат доказательством текущей совместимости.
