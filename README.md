# sber-npf-platform-v

Комплект интеграции документооборота СберНПФ с Platform V: модель DataSpace, права, разрешённые GraphQL, справочники и BPMN для ПДС и КИД ОПС. Прикладные правила изменения документов принадлежат Corelia; текущие BPMN создают документы и меняют их статусы.

## Сборка комплекта

Из корня репозитория, с Bash и Python 3:

```bash
bash scripts/package-platform-v.sh
```

Результат — dist/sber-npf-platform-v.zip. Состав определяется [.info.meta.json](.info.meta.json); документация и исходники соседних сервисов в архив не входят. Сборка архива не устанавливает модель и не проверяет её принятие SDK платформы.

seed-dictionaries.sh сейчас не является полноценным способом установки обоих видов: обрабатывает только первую запись каждого справочника и содержит настройки старого окружения. Ограничения скрипта и LCUI описаны в [operations.md](docs/operations.md); перед использованием на стенде их необходимо учитывать.
